The demo web app, screen by screen

One web app with three faces: attendees join an event with a wallet and a selfie, organizers create and run events, and a smartphone acts as the event camera that streams to our oracle.

Turn any phone into the oracle's camera

Why a web page, not an app

Any phone browser can open the camera and stream frames. Nothing to install at the venue, and a second phone is a second camera.

Needs HTTPS

Phone browsers only allow the camera on HTTPS pages. Our Cloudflare tunnel already serves the app over HTTPS, so the QR code points at the public URL.

Bandwidth

About 8 frames per second at 640 px is plenty for faces a few metres away. Raise it if people at the back of the room are missed.

Decisions for the demo

Names on the stage screen

Boxes need a label. Suggested: ask for a first name when joining. Otherwise show the short wallet address.

MetaMask on Solana

MetaMask's Solana support should appear through the standard Solana wallet connector. Check this on day one; Phantom is the fallback, behind the same button.

Login provider

Either our own "sign a message" check in FastAPI, or Supabase's wallet sign-in if it supports Solana. Both give one-click login.
